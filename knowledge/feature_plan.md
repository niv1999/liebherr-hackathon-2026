# Feature plan: LPR audit tool (Phase 4 idea pool, agreed 17 Nov 2026)

## Build status (17 Nov 2026, evening): HeLPR v2
Built and tested on EP:, MediaMarkt, expert (Euronics/OTTO shown as blocked): everything in A–G below **except**
EmpCo flag (#21, bonus) and a dedicated SK3 "premium" vision check of lower page parts. Also built beyond the list:
brand-page checks incl. technology subpage, shop search tests, per-SK scores, escalation to the vision judge,
AI connections UI, EN/DE, dark mode, Data section (criteria/models/retailers), viewing older audits.
Open: real AI judge quality (needs a valid Gemini/Claude key), OTTO/Elektroplus URLs, deployment.


**Focus: purely the internal tool for Liebherr employees.** No shopper-facing features and no retailer portal (for now).
Based on the team's idea pool (numbers = original idea numbers) plus additions from Liebherr's answers (`liebherr_answers.md`).

## A · Running audits
- 8 Automatic runs at a configured interval (Liebherr: weekly is enough)
- 9 Manual run whenever an employee wants
- 11 Manual run for one specific retailer instead of all
- 10 AI judges one specific criterion at one specific retailer
- 13 Add a new retailer
- Blocked shops (e.g. Euronics, Otto): **no upload mode**. The tool just shows "blocked for bots → needs manual assessment". That also covers Liebherr's request to document access restrictions.
- Alert/notification **whenever an audit finishes** (with a summary: score, change, new failures)

## B · Scoring and criteria control
- 2 Score per retailer
- 6 Add / remove criteria
- 12 Weights per criterion, and 17 priority labels (low/medium/high) that the AI takes into account. These overlap and may be merged into one control.
- 18 SK class filter (SK1 / SK2 / SK3)
- Default block weights from Liebherr: **Visibility (highest) > Services > Advice (lowest)**
- Each verdict labelled by source: **rule / AI / needs a human**

## C · Trust and human control
- 4 Evidence per AI verdict: screenshot + reasoning
- 5 Override an AI decision manually
- 7 Write feedback on a verdict to improve future judgements
- 14 Edit the prompt/instruction for a specific criterion
- Confidence level per AI verdict; low confidence → flagged for a human

## D · Content quality checks
- 20 Master-data mismatch alert: EAN, model name or logo differs from Liebherr's official data
- 21 EmpCo green-claim flag (**bonus only**, Liebherr: nice to have)
- Feature and benefit text check: are Liebherr technologies (BioFresh, NoFrost…) and their benefits explained correctly and completely, compared with the official feature texts in the product CSV. (**Liebherr's #1 pain point**)
- SK3 premium product page check (AI judge). (Liebherr pain point)
- Official image check: are the shop's pictures Liebherr's official images?
- **Return-risk flag per criterion**: e.g. missing installation dimensions or door-handle info. Counts negatively in the score. The retailer overview shows the **number of return risks found** in a dedicated table. (Liebherr's real example: customer returned an appliance without a door handle.)

## E · Overview and insights
- 1 Comparison of retailers
- 15 Overview page per retailer: what's good / what's missing
- 19 Historical trend dashboard (progress over time)
- Product count per retailer: **how many Liebherr products are listed, and how many are available to buy** (explicitly requested by Liebherr)

## F · AI readiness
- 3 AI-readiness score with a **clear, repeatable method** (Liebherr has none and asked for our idea)
- 25 Live AI shopper simulator: type a question ("fridge for a 60 cm niche") and see how an AI answers using only that shop's data
- Shop search test: does searching "Liebherr" / "Kühlschrank" in the shop lead to Liebherr products and the brand page?

## G · Reports for retailers (generated by Liebherr staff)
- 16 PDF report
- 22 To-do list for the retailer
- 23 Deadline and suggested fix per failed criterion, shown in the report
- 24 One-click asset recovery: link to the right Liebherr asset (logo, energy label, video) for anything missing
- Excel export (Liebherr works in Excel today)

## Dropped (and why)
| Idea | Reason |
|---|---|
| Upload mode for blocked shops | Not needed: show "blocked → manual assessment" instead |
| Separate access log | Same as above |
| Accuracy check vs our own manual audit | No time |
| Outdated-content check (old teaser, discontinued models) | Team unsure the data supports it. Note: the assortment xlsx has a Neuheit/Auslauf (new/discontinued) column and the 2026_09 asset pack has the current teasers, so this could come back later. |
| Retailer self-check portal | Too much. PDF/Excel/to-do list cover retailer communication. |
| "Will it fit?" shopper helper / any Option B feature | Focus is the internal tool |
